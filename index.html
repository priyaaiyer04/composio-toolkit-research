The agent: what it does, where a human stepped in

// pipeline, not a one-shot prompt

Pipeline

1
Search-grounded research call

For each app, Claude is given the app name + hint and the web_search tool, instructed to search first and answer only from what it reads — not from parametric memory alone.

2
Strict-schema extraction

The model returns one JSON object per app: category, auth, self-serve/gated + reason, API surface, MCP status, verdict, blocker, evidence URL. No prose, no markdown fences.

3
Honesty constraint

If no first-party docs are found, the agent is instructed to say so — verdict: blocked, blocker explained — instead of guessing. This is what caught fanbasis and Consensus.

4
Verification pass (separate step)

A 20-app stratified sample is re-checked by hand/live-search against the docs specifically for the fields most likely to drift: access tier and MCP status. See the Verification section.

Where a human was needed: judging ambiguous "is this even a toolkit" cases (a local CLI like Sherlock or Mermaid CLI vs. a hosted API), resolving the two apps with no discoverable public docs, and signing off on the final buildability verdict — that's a product call, not just a factual lookup.

All 100 evidence URLs are also checked by a reproducible HTTP pass. Sources that require authentication or block automated clients are reported separately from missing pages.


    
Browser-use pass: does the live page actually say what we claimed?

    
A separate loop opens all 100 evidence URLs in a real headless browser (Playwright/Chromium), waits for full render, and checks whether the recorded auth/MCP claims literally appear on the page — not just whether the URL returns HTTP 200.

    

      
41
apps where every recorded claim was found on the rendered evidence page

      
29
apps where some claims were confirmed, some not — worth a manual glance

      
30
apps with no match — spot-checked by hand (Salesforce, Slack); usually the evidence URL is a landing/catalog page one click from the specific proof, not a false claim
